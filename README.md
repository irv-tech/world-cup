# World Cup

## Overview
A full-stack World Cup analytics platform built with React, FastAPI, SQLite, JWT authentication, and REST APIs.

## Features
- Team directory with World Cup stats
- Player profiles
- Match list and calendar view
- User registration and login
- JWT authentication
- Protected dashboard
- Favorite teams and players
- Backend API proxy for external football data
- SQLite database persistence

## Tech Stack
- React
- JavaScript
- FastAPI
- Python
- SQLite
- SQLAlchemy
- JWT
- Git/GitHub

## Architecture
React frontend communicates with a FastAPI backend. The backend handles authentication, database operations, and external API calls.
